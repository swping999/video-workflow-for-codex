# Workflow reference

## Free one-command path

```bash
<plugin-root>/scripts/video-workflow doctor
<plugin-root>/scripts/video-workflow build --brief "做一个讲 MCP 的竖版科普视频" --script /absolute/generated-script.txt --output /absolute/new-project --slug mcp-explainer --type explainer --format portrait --theme whiteboard --quality high
```

`build` creates a new isolated project, exports exact narration jobs, synthesizes with the operating system's free voice, balances and normalizes audio, measures the real cue timeline, verifies the project, and renders the final MP4. It refuses to overwrite an existing output directory.

If `doctor` reports missing packages, change into `<plugin-root>/runtime` and run `npm ci`. Linux also needs the free `espeak-ng` package. macOS uses `say`; Windows uses `System.Speech`.

## Brief decomposition

| Signal | Choice |
| --- | --- |
| concept, definition, education | `explainer` |
| tools, Skills, recommendations, numbered items | `listicle` |
| tutorial, SOP, sequence, how-to | `workflow` |
| A/B, difference, before/after | `comparison` |
| feature, launch, product, advertisement | `promo` |
| metrics, rankings, GitHub activity, trends | `data-story` |

Format routing: short-form and vertical-platform requests → `portrait` (1080×1920); 小红书 or 4:5 → `social` (1080×1350); horizontal, YouTube, PPT, or presentation → `landscape` (1920×1080).

Theme routing: approachable education → `whiteboard`; list and editorial content → `editorial`; data and developer topics → `tech`; product and advertising → `product`. User instructions override every default.

The generated script should normally use 5–8 paragraphs, one scene per paragraph, with complete punctuation. Keep a clear hook, useful body, and concise close. Do not pad duration with repeated claims or long pauses.

## Staged commands

```bash
<plugin-root>/scripts/video-workflow create --script /absolute/script.txt --output /absolute/new-project --slug episode-name --type auto --format portrait --theme editorial
<plugin-root>/scripts/video-workflow export --project /absolute/new-project
<plugin-root>/scripts/video-workflow synthesize --project /absolute/new-project --provider system
<plugin-root>/scripts/video-workflow process-audio --project /absolute/new-project
<plugin-root>/scripts/video-workflow verify --project /absolute/new-project
<plugin-root>/scripts/video-workflow render --project /absolute/new-project --quality high
```

Use `--provider files` only to keep exported cue IDs while supplying the user's own authorized audio under `.media/raw-cues/`. The free core never sends copy or audio to a cloud speech endpoint.

## Locked sources

`brief.locked.txt` stores the user's original one-sentence request when brief mode is used. `script.locked.txt` stores the exact script generated by Codex or supplied by the user. Blank-line-separated paragraphs become scenes. Complete punctuation becomes caption and narration cues. `story-source.json` records hashes and is the only structured source used for narration jobs and rendered captions.

Safe edits include titles, eyebrow labels, layout choices, visual cards, theme, optional image assets, and render format. For revised wording, create a new project instead of mutating provenance.

## Visual and audio defaults

The default video uses code-rendered typography, diagrams, cards, arrows, shapes, and GSAP motion. It needs no paid image generator and includes no identifiable presenter. Optional image prompts are exported for users who choose to add their own assets, but they are not required for a complete video.

System speech is converted to 48 kHz mono WAV. Each cue is dynamically balanced, scene tracks target approximately -16 LUFS and -1.5 dBTP, and scene timing is measured from the resulting files.

## Failure recovery

- Missing system speech: install `espeak-ng` on Linux, or use the staged `files` path.
- Missing cue: regenerate or provide only that cue again.
- Locked-copy or brief mismatch: stop and create a new project from corrected input.
- Loudness or peak failure: rerun `process-audio` from raw cues.
- Render failure: preserve the verified project and retry rendering without rewriting copy or speech.
